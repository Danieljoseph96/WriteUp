## 1️⃣ Relational Databases (SQL)

**Examples:** MySQL, PostgreSQL, Oracle Database  

<ul>
<li>Data is stored in tables (rows & columns) with predefined schema.</li>
<li>Uses SQL (Structured Query Language) for queries.</li>
<li>Supports ACID properties (Atomicity, Consistency, Isolation, Durability).</li>
<li>Best for structured data like banking systems, ERP, and transactional apps.</li>
</ul>

## 2️⃣ NoSQL Databases

**Examples:** MongoDB, Cassandra, Redis  

<ul>
<li>Schema-less or flexible schema.</li>
<li>Designed for scalability and high performance.</li>
<li>Types include:
    <ul>
        <li>Document (MongoDB)</li>
        <li>Key-Value (Redis)</li>
        <li>Column-family (Cassandra)</li>
        <li>Graph (Neo4j)</li>
    </ul>
</li>
<li>Used in real-time apps, big data, and distributed systems.</li>
</ul>

## 3️⃣ File Storage System

**Examples:** Local file systems, Amazon S3  

<ul>
<li>Stores data as files (text, images, videos).</li>
<li>Simple and easy to use.</li>
<li>Not optimized for complex queries.</li>
<li>Used for backups, media storage, logs.</li>
</ul>

---

## 4️⃣ Object Storage

**Examples:** Amazon S3, Google Cloud Storage  

<ul>
<li>Stores data as objects with metadata.</li>
<li>Highly scalable and durable.</li>
<li>Ideal for large unstructured data (images, videos, ML datasets).</li>
<li>Used in cloud-native applications.</li>
</ul>

---

## 5️⃣ In-Memory Databases

**Examples:** Redis, Memcached  

<ul>
<li>Data stored in RAM instead of disk → very fast.</li>
<li>Used for caching, session storage.</li>
<li>Not ideal for permanent storage unless backed up.</li>
</ul>

---

## 6️⃣ Graph Databases

**Examples:** Neo4j  

<ul>
<li>Stores data as nodes and relationships (edges).</li>
<li>Efficient for connected data like social networks.</li>
<li>Used in recommendation systems, fraud detection.</li>
</ul>

---

## 7️⃣ Data Warehouses

**Examples:** Amazon Redshift, Google BigQuery  

<ul>
<li>Designed for analytics and reporting.</li>
<li>Handles large volumes of historical data.</li>
<li>Supports complex queries (OLAP).</li>
<li>Used in business intelligence.</li>
</ul>

---

## 8️⃣ Time-Series Databases

**Examples:** InfluxDB  

<ul>
<li>Stores data with timestamps.</li>
<li>Optimized for monitoring, IoT, logs.</li>
<li>Efficient for time-based queries.</li>
</ul>

---

## 9️⃣ Key-Value Stores

**Examples:** Redis, DynamoDB  

<ul>
<li>Data stored as key → value pairs.</li>
<li>Very fast lookup.</li>
<li>Used in caching, session management.</li>
</ul>

---

## 🔟 Distributed Databases

**Examples:** Apache Cassandra  

<ul>
<li>Data distributed across multiple nodes.</li>
<li>Provides high availability and fault tolerance.</li>
<li>Used in large-scale applications (e.g., Netflix, social media).</li>
</ul>
